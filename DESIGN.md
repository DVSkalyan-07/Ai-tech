# Architecture & System Design

## Core Components
- **Knowledge Brain (Task 1):** Built using FastAPI for low-latency asynchronous API endpoints to process RAG queries and fetch sitemaps.
- **Inbox Agent (Task 2):** Rule-based logic engine that triages client emails into predefined categories and priority buckets.
- **Meeting-to-Scope (Task 3):** Automated parser that extracts key deliverables and objectives from transcripts to assemble structured Scopes of Work.
