# AI Tech Consultant Capstone Project

## Overview
This repository contains the solution for the AI Tech Consultant capstone, featuring three core modules:
1. **Task 1: Knowledge Brain** - FastAPI backend for RAG-based sitemap ingestion and query handling.
2. **Task 2: Inbox Agent** - Automated email triage and prioritization engine.
3. **Task 3: Meeting-to-Scope** - Multi-agent synthetic scope of work (SOW) generator from transcripts.

## Setup & Execution
Navigate to the respective task folders and run scripts using Python.
